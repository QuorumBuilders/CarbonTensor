# CarbonTensor Frontend Micro-PR Roadmap

A sequenced, atomic delivery plan to construct the complete CarbonTensor supply-side data and payout application.

| PR # | Title | Scope Summary | Status |

| **PR #2** | **Google Sans Typography & Brand System Landing Page** | Configure typography, header navigation, hero statistics, and value proposition cards. | **Complete** |
| **PR #3** | **Seeded Domain Types & Mock Data Layer** | Establish TypeScript domain models, seeded Nigerian rice cooperative records, and mock adapter. | **Complete** |
| **PR #4** | **Demo Presentation Controller & Shell** | Implement persistent demo state switcher, breadcrumb shell, and cooperative selector. | Planned |

| **PR #6** | **Recharts AWD Time-Series & Sensor Simulator** | Water table depth chart (-15cm threshold line), dry-down cycle tracker, and sensor jitter simulator. | Planned |
